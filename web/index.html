FROM SEQUENCER TO SCENE

Bring your show to life.

No physical controller is needed. This preview receives the RGB channel data that xLights sends to lights.

  1. 01
    Patch your display

    Use the fixture channel ranges in the Display Patch panel. Import the generated custom models in the xlights/ folder, or map your own RGB models to the same channels.

  2. 02
    Add an Ethernet controller in xLights

    Choose DDP, set IP to 127.0.0.1, and set Channels to —. Keep channel numbering starting at 1. The receiver uses UDP 4048.

    For E1.31, use unicast, start universe 1, — universes and 510 channels per universe.

  3. 03
    Switch to Live input

    Enable Output to Lights in xLights, then play your sequence. The network monitor counts received packets. Disable frame sync for this preview.

  4. 04
    Test it in Unreal Engine

    Open unreal/ChristmasLights/ChristmasLights.uproject after following its README and running the asset setup. Press Play. The bridge forwards the same RGB frames to UDP 4049.

Quick network test: python tools/send_test.py --protocol ddp
Use Live input to view the sender. Stop it with Ctrl+C.
